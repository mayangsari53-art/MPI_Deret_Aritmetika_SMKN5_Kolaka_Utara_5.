Deret Aritmetika

Deret aritmetika adalah penjumlahan suku-suku barisan yang memiliki beda tetap.

2 + 5 + 8 + 11 + 14

Bedanya selalu 3: 5 − 2 = 3, 8 − 5 = 3, dan seterusnya.

Sₙ = n/2 [2a + (n − 1)b]
Sₙ = n/2 (a + Uₙ)

Keterangan: Sₙ = jumlah n suku pertama; a = suku pertama; b = beda; n = banyak suku; Uₙ = suku ke-n.

Contoh: Hitung 2 + 5 + 8 + 11 + 14.
a = 2, b = 3, n = 5.
S₅ = 5/2 [2(2) + (5 − 1)3] = 5/2 (16) = 40.

Deret Geometri

Deret geometri adalah penjumlahan suku-suku barisan yang memiliki rasio tetap.

3 + 6 + 12 + 24

Rasionya selalu 2: 6 ÷ 3 = 2, 12 ÷ 6 = 2, dan seterusnya.

Sₙ = a(rⁿ − 1)/(r − 1), r ≠ 1
Sₙ = a(1 − rⁿ)/(1 − r), r ≠ 1

Keterangan: a = suku pertama; r = rasio; n = banyak suku. Jika r = 1, Sₙ = na.

Contoh: Hitung 3 + 6 + 12 + 24.
a = 3, r = 2, n = 4.
S₄ = 3(2⁴ − 1)/(2 − 1) = 3 × 15 = 45.
Ingat! Aritmetika: selisih/beda tetap. Geometri: perbandingan/rasio tetap.
